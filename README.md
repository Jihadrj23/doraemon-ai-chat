# Doraemon AI Chat

Build a stunning, ultra-premium AI chat web application named "Doraemon" featuring a custom Doraemon-themed UI and background watermark.



Strict UI/UX & Theming Requirements:



1. Background & Watermark:

- Main Background: Deep obsidian matte black (`#000000`) blended smoothly with Doraemon's signature bright sky blue (`#0369A1` / `#0284C7`) and soft gradient glow.

- Chat Area Watermark: In the center/background of the chat interface, place a very subtle, transparent, high-end watermarked illustration of Doraemon's happy smiling face with low opacity (glassmorphism style) so it doesn't interfere with reading text, but gives a gorgeous branded aesthetic.



2. Top Header:

- Left side: A cute Doraemon avatar/icon followed by the English brand name "Doraemon" in a bold, clean modern font.

- Right side: Settings or new chat icons.



3. Chat Interface & Message Bubbles:

- User & AI message bubbles styled with sleek Frosted Glassmorphism (`rgba(255, 255, 255, 0.05)` with thin borders and backdrop blur).

- Doraemon's theme accents: Red (`#EF4444`) and Golden Yellow (`#FBBF24`) highlights for buttons or active states.



4. Bottom Floating Input Bar:

- A rounded glassmorphism input box fixed at the bottom.

- Left side: A "+" attachment icon.

- Center: Placeholder text saying "Ask Doraemon anything..."

- Right side: Voice input icon and a stylish blue send button.
